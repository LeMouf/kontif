# Starting point — 2026-09-06

The owner selected the existing empty public repository LeMouf/kontif as the
ecosystem registry authority. This initial implementation starts a fresh history;
it does not import a development monorepo, company source or component history.

Core 0.284.2 was already published independently. The draft records its existing
artifact and source references, not the current Core main branch. Those recorded
publication observations are not a new cryptographic verification.

Implemented scope: current registry draft, closed structural schema, cross-ID
checks, historical tombstone/rename checks and deterministic digest. Deferred:
ecosystem releases and approvals, immutable publication, CI, broader inventory,
site projection and any partner agreement. No ecosystem version is assigned.
